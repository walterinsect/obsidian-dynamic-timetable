# Changelog

## 0.4.0
- Marketplace 用メタデータ(アイコン、カテゴリ、キーワード)を追加。

## 0.3.2
- 設定画面をカテゴリ別に整理。`taskTemplateMap` / `categoryColorMap`(GUI で編集可能)と `Open Settings` コマンドを追加。

## 0.3.1
- 打刻を既定でオン。完了行の実績開始時刻を `@ YYYY-MM-DD HH:mm` で記録(`@ HH:MM` 等の旧形式も読み取り可)。

## 0.3.0
- `(@created)` / `(@done)` 打刻、定型タスク挿入コマンド(Insert Task Template, スロット 1–5)。

## 0.2.0
- Statistics ビュー。

## 0.1.0
- Timetable ビュー、Complete / Interrupt コマンド(Obsidian 版 Dynamic Timetable のポート。元: L7Cy, MIT)。
